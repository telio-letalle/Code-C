# Code-C

Fork du projet [Code-C](https://github.com/letallemartin/Code-C), réalisé à l'origine par mon frère.

Ce dépôt m'a permis de découvrir et de pratiquer le fonctionnement de **GitHub**, notamment le travail avec les **Pull Requests**.

L'objectif principal était de contribuer au projet tout en apprenant les principes de collaboration avec Git et GitHub.

## Ce que j'ai appris

- Création de Pull Requests
- Contribution à un dépôt forké
- Synchronisation d'un fork avec le dépôt d'origine
